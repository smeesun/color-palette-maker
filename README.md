# COLpama(カラパマ)

3DCG・イラスト制作者向けの配色提案アプリです。作品の配色に迷ったときに、セレクト(色から探す)・カテゴリ(条件から探す)・ラッキーカラー(ランダム提案)の3通りの方法で、あらかじめ登録した配色データの中から3色の組み合わせを提案します。

## 動作環境

- Python 3.14 で開発・動作確認しています
- 対応OS: Windows(フォントの同梱読み込み処理がWindows専用のAPIを使用しているため)

## セットアップ

```
pip install -r requirements.txt
```

## 実行方法

```
python TEST03.PY
```

アプリ本体です。プロジェクトフォルダのどこから実行しても、実行時に自動でこのファイルがある場所に移動してから`colpama.db`や`images/`、`fonts/`を読み込むので、実行場所を気にする必要はありません。

```
python preset_entry_tool.py
```

配色データを`colpama.db`に登録するための、データ入力専用ツールです。アプリ本体とは別に単体で起動できます。

## フォントについて

見出しなどに`fonts/`フォルダ内のカスタムフォント(ふてほど丸ゴシック、あめふりドロップス無料版、マメロン)を使用しています。パソコンにインストールされていなくても、起動時に自動で(インストールせず、このアプリの実行中だけ使える形で)読み込むようになっているため、追加の作業は不要です。

起動時にコンソールへ`[フォント確認] ◯◯ : OK`のように読み込み結果が出力されるので、見た目が崩れて見える場合はここを確認してください。

## ファイル構成

- `TEST03.PY` — アプリ本体
- `preset_entry_tool.py` — 配色データ登録ツール
- `colpama.db` — 配色データ(SQLite)
- `images/` — アプリ内で使用する画像
- `fonts/` — 同梱フォント
